# 🚀 JobFinder & AI Matcher Telegram Bot

Интеллектуальная Telegram-платформа для поиска работы и подбора кандидатов с интеграцией **Groq AI (Llama 3.3 70B)**, парсингом внешних вакансий и базами данных **PostgreSQL**.

Проект позволяет кандидатам искать как внутренние, так и внешние вакансии, загружать текстовые резюме, откликаться и сохранять предложения, а работодателям — публиковать вакансии, отслеживать отклики и проводить автоматизированный **AI-анализ соответствия** резюме требованиям вакансии.

---

## 🛠 Стек технологий

* **Язык программирования:** Python 3.10+
* **Telegram Bot API Framework:** `aiogram 3.x` (поддержка Router, FSM, Inline/Reply клавиатур)
* **Асинхронные HTTP-запросы:** `aiohttp` (асинхронный клиент для работы с внешними API)
* **База данных:** PostgreSQL
* **Драйвер БД:** `asyncpg` (полностью асинхронное взаимодействие с PostgreSQL)
* **AI & LLM Integration:** `groq` (модель `llama-3.3-70b-versatile` для анализа CV)
* **Конфигурация:** python-dotenv
